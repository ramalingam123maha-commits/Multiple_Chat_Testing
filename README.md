# Online Resume Builder

A browser-based resume builder where users can enter personal information, work experience, education, and skills while seeing a live resume preview. The resume can be downloaded as a PDF using html2pdf.js.

## Features

- Personal info, summary, work experience, education, and skills inputs
- Add and remove multiple work and education entries
- Live resume preview beside the form
- PDF export powered by html2pdf.js
- Responsive layout for smaller screens

## Usage

Open `index.html` in a browser. Fill out the form fields, review the live preview, and use **Download PDF** to export the resume.
